# BetFut ⚡

Plataforma de análisis inteligente de apuestas deportivas con IA + datos reales.

## Archivos del proyecto

```
betfut-project/
├── index.html
├── package.json
├── vite.config.js
├── .gitignore
└── src/
    ├── main.jsx
    └── App.jsx
```

## Cómo desplegar en Vercel (gratis)

1. Sube esta carpeta a un repositorio en GitHub
2. Ve a vercel.com → "Add New Project"
3. Conecta tu repositorio de GitHub
4. Vercel detecta Vite automáticamente → clic en "Deploy"
5. En ~2 minutos tienes tu URL: `https://betfut-pro.vercel.app`

## Configuración en la app

Una vez desplegada, ve a la pestaña ⚙️ Config:

- **Claude API Key**: obtén en console.anthropic.com
- **Worker URL**: tu Cloudflare Worker (`https://xxx.workers.dev`)
- **API-Football Key**: obtén en dashboard.api-football.com


La configuración se guarda en tu navegador automáticamente.
